# Support & Community Resources

Need help getting started with **MineOS**, configuring hardware endpoints, or troubleshooting deployment? Here are the official support channels and resources.

---

## Getting Help

### 1. GitHub Issues
- **Bug Reports**: If you encounter unexpected behavior, telemetry ingestion issues, or rendering anomalies, [open a GitHub Issue](https://github.com/NitikasriJeyanAchary0109/mineos/issues).
- **Feature Requests**: To suggest new sensor driver support, DGMS compliance modules, or 3D visualization enhancements, submit an issue tagged `enhancement`.

### 2. Documentation & API Reference
- [Architecture & Endpoints Guide](API.md): Detailed schemas for Edge Jetson, Wearable Health, and Gas Grid ingestion.
- [Contribution Guidelines](CONTRIBUTING.md): Instructions for setting up development environments and submitting PRs.
